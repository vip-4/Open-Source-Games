Key facts

  • Community-maintained catalog of open-source games, any genre and any platform.
  • Organized into Browser-Based, Desktop and Mobile sections with genre-based categories.
  • Each entry links to its source code; many also include a playable demo.
  • Contributions are welcome through issues and pull requests on the upstream repository.
  • Published under the MIT License.

Open-Source-Games

Open Source Games

Below is a list of open source games - old school text adventures, educational games, 8-bit platform games, browser-based games, indie games, GameJam projects, etc…

Contributing

If you’d like to add a game to the list or found a bug? Please create an Issue, or fork this repository and submit a pull request (click here to edit this file from github).

Any game is accepted as long as it is open source. No matter what platform the code is published on, GitHub, GitLab, Code Sandbox, etc…

Frequently asked questions

What is Open Source Games?

A community-maintained, curated list of open-source games spanning browser, desktop and mobile platforms, including text adventures, educational games, 8-bit platformers, browser games, indie titles and game jam projects.

Which genres and platforms are covered?

The catalog is organized into Browser-Based, Desktop and Mobile sections, with categories such as arcade, FPS, RPG, MMORPG, strategy, racing, sandbox, puzzle/card/board, programming and more.

How can I submit a game or report a broken link?

Open an issue on the upstream repository, or fork the repo and send a pull request. Any game is accepted as long as it is open source, regardless of where its code is hosted.

Can I play the games directly from the list?

Yes. Many entries include a Play link pointing to a live demo, alongside a Source link to the project repository.
